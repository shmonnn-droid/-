# סנכרון ענן – הכרם יומן כלות

היומן שומר את הנתונים במכשיר (localStorage). כדי שהנתונים יישמרו גם בענן ויסונכרנו בין כמה טלפונים/מחשבים,
מתקינים פעם אחת סקריפט קטן בחשבון ה-Google שלך. הסקריפט שומר את כל היומן כקובץ ב-Google Drive
(ובנוסף כטבלת Google Sheets לצפייה נוחה).

## התקנה (פעם אחת, כ-5 דקות)

1. נכנסים ל-<https://script.google.com> עם חשבון ה-Google של העסק ולוחצים **New project** (פרויקט חדש).
2. מוחקים את התוכן שבקובץ `Code.gs` ומדביקים במקומו את כל התוכן של הקובץ `sync/apps-script.gs` מהמאגר.
3. בשורה `const TOKEN = 'CHANGE_ME_TO_A_LONG_SECRET';` מחליפים את הטקסט בקוד סודי ארוך משלך
   (למשל 20 תווים מעורבבים). שומרים (Ctrl+S).
4. לוחצים **Deploy → New deployment**, בוחרים סוג **Web app**:
   - **Execute as:** Me (אני)
   - **Who has access:** Anyone (כל אחד)
   לוחצים **Deploy** ומאשרים את ההרשאות (Google יבקש גישה ל-Drive ול-Sheets של החשבון).
5. מעתיקים את הכתובת שמתקבלת (מסתיימת ב-`/exec`).
6. ביומן: לוחצים **☁️ סנכרון ענן** בתחתית המסך, מדביקים את הכתובת ואת הקוד הסודי, ולוחצים **חיבור וסנכרון**.
7. בכל מכשיר נוסף (טלפון של שותפה וכו') חוזרים על שלב 6 עם אותה כתובת ואותו קוד.

## איך זה עובד

- כל שינוי נשמר מיד במכשיר, ותוך שנייה נשלח לענן.
- בפתיחת היומן, בחזרה לחלון ופעם בדקה – היומן בודק אם יש בענן גרסה חדשה יותר ממכשיר אחר וטוען אותה.
- בלי אינטרנט: השינויים נשמרים במכשיר ומסומנים "ממתין", ונשלחים אוטומטית כשהחיבור חוזר.
- אם שני מכשירים שינו בו-זמנית – הגרסה ששמרה אחרונה היא זו שנשמרת (השנייה מקבלת אותה).
- בתחתית המסך מופיע מצב הסנכרון (מסונכרן / ממתין / שגיאה).

## אבטחה

- הנתונים (שמות וטלפונים של לקוחות) נשמרים רק ב-Drive שלך.
- מי שיש לו גם את הכתובת וגם את הקוד הסודי יכול לקרוא ולכתוב – אל תשתפי אותם מחוץ לצוות.
- להחלפת קוד: משנים את `TOKEN` בסקריפט, **Deploy → Manage deployments → Edit → Version: New** ומעדכנים בכל מכשיר.

## עדכון הסקריפט בעתיד

אחרי שינוי בקוד הסקריפט: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
הכתובת נשארת אותה כתובת.
